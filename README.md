# SONS UZ ÇAY DEMLEME SİMÜLASYONU

## Resmi Açıklama

Bu depo, insanlığın en büyük sorularından birini çözmek için tasarlanmıştır: **Çay neden hiç demlenmiş gibi hissettirmez?**

Bilimsel araştırmalar gösteriyor ki çay, demlenme sürecini tamamlamadan önce zamanın dokusunu büker. Bu simülasyon, bu fenomeni laboratuvar koşullarında yeniden üretir.

## Özellikler

- Sonsuz döngü (garanti)
- Rastgele yanlış "hazır" alarmları
- Klavye kesintisiyle durdurulabilir (ama çay asla demlenmez)
- %100 gerçekçi demlenme sesi (hayal gücünüze bağlı)

## Kullanım

```bash
python3 cay_simulyasyonu.py
```

Ctrl+C ile çıkabilirsiniz. Çay demlenmeye devam eder.

## Uyarı

Bu simülasyon gerçek çay demlemez. Gerçek çay demlemek isterseniz çaydanlık kullanın. Biz sadece felsefi boyutuyla ilgileniyoruz.
